# Privacy and safe sharing

CareFlow Health is a fictional portfolio scenario. Use synthetic tickets and test data in public examples.

Before publishing workflow exports or screenshots:

- Remove credential identifiers, names, tokens and secret values.
- Replace private spreadsheet IDs and cached resource URLs with placeholders.
- Hide customer names, email addresses and issue descriptions.
- Check URLs, browser tabs, execution logs and node parameters for private information.
- Confirm permission to publish every screenshot and workflow file.
- Keep AI-generated summaries and draft replies under human review.

The published workflow JSON has been sanitised for this repository. After importing it, reconnect credentials and select your own test spreadsheet in n8n. Never commit those private configuration values back to the public repository.

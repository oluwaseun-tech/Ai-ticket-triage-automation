# Data dictionary

The names below reflect the form-response and support-queue schema recorded in the workflow export. Some form-question labels contain line breaks; preserve exact headers when writing n8n expressions.

| Source / output field | Purpose |
|---|---|
| Timestamp | Form-response timestamp and current row-matching key |
| Question 1 — Full Name | Customer name supplied in the form |
| Question 2 — Email Address | Customer email supplied in the form |
| Question 3 — Issue Category | Customer-selected issue category |
| Question 4 — Subject | Short description of the issue |
| Question 5 — Describe your issue | Customer's free-text description |
| Question 6 — Priority | Customer-submitted priority |
| AI Summary | Concise issue summary generated by the model |
| AI Category | AI-suggested category |
| AI Sentiment | AI-suggested sentiment label |
| AI Draft Reply | Draft response for human review |
| Status | Workflow/review status; the Code node sets Pending after valid parsing |

The model also returns a `priority` field. The current spreadsheet has no separate AI Priority column, so the model suggestion is not written to the sheet. Add a dedicated column and refresh the Google Sheets node schema before mapping it.
